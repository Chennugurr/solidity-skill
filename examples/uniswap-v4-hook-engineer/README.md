# Example: Uniswap v4 Hook Engineer

## Prompt

```text
Use skills/uniswap-v4-hook-engineer/SKILL.md.

Design a Uniswap v4 hook that charges a dynamic fee based on pool-specific configuration.
Define enabled callbacks, hook permissions, PoolManager assumptions, pool-specific storage, admin powers, manipulation risks, tests, and deployment notes.
Consult skills/uniswap-v4-hook-engineer/references/hook-design.md and skills/uniswap-v4-hook-engineer/references/hook-testing.md.
```

## Expected Agent Behavior

- Confirm package/interface version before coding.
- Define permissions before implementation.
- Keep callback logic minimal.
- Use pool-specific storage.
- Include callback, permission, and manipulation tests.
