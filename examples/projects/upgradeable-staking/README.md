# Upgradeable Staking Project

This standalone Foundry project demonstrates a UUPS staking contract, locked implementation initialization, authorized upgrades, state preservation, and a V2 withdrawal-delay migration.

```bash
forge soldeer install
forge test
```

Use `upgradeable-contract-engineer`, `staking-restaking-engineer`, `foundry-test-writer`, and `protocol-operations-engineer` when adapting it. Dry-run every upgrade and independently review storage compatibility.
