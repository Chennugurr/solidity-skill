# ERC4626 Vault Project

This standalone Foundry project demonstrates a minimal ERC4626 vault with a virtual-offset defense, deployment script, unit/fuzz tests, and conservation invariants.

```bash
forge soldeer install
forge test
```

Use `solidity-builder`, `defi-accounting-engineer`, `foundry-test-writer`, and `solidity-auditor` when adapting it. This is an educational draft, not an audited vault.
