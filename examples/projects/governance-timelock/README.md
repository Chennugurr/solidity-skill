# Governance Timelock Project

This standalone Foundry project demonstrates an ERC20Votes token, OpenZeppelin Governor, TimelockController, role handoff, a proposal lifecycle test, and deployment script.

```bash
forge soldeer install
forge test
```

Use `protocol-spec-writer`, `solidity-builder`, `evm-deployment-engineer`, and `protocol-operations-engineer` when adapting it. Governance parameters and voter distribution require project-specific review.
