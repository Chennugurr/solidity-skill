# Staking Restaking Example Prompts

Use `staking-restaking-engineer` for prompts such as:

```text
Specify a pooled restaking vault with operator delegation, reward fees, a seven-day withdrawal queue, slashing through finalization, and validator-exit failure handling. Define accounting invariants.
```

Expected behavior: reconcile active and queued claims, define slash allocation at every lifecycle point, and disclose operator and service trust.
