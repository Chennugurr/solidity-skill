# Example: Token Launch Builder

## Prompt

```text
Use skills/token-launch-builder/SKILL.md.

Design a transparent fixed-supply ERC20 launch.
No taxes, no blacklist, no trading switch, no upgradeability.
Include allocation table, liquidity plan, vesting notes, owner/admin powers, tests, and launch disclosure.
Consult shared/references/security-posture.md and skills/token-launch-builder/references/launch-mechanics.md.
```

## Expected Agent Behavior

- Avoid hidden launch controls.
- State that supply is fixed.
- Document allocations and liquidity handling.
- Recommend multisig if admin powers remain.
- Include tests and disclosure notes.
