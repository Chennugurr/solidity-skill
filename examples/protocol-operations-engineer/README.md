# Protocol Operations Example Prompts

Use `protocol-operations-engineer` for prompts such as:

```text
Prepare a decoded Safe batch and runbook that transfers upgrade authority to a timelock, revokes the temporary deployer, verifies every role afterward, and defines rollback and incident communication steps.
```

Expected behavior: inventory current authority, produce reviewable placeholders rather than guessed addresses, require a dry-run, and list explicit postchecks.
