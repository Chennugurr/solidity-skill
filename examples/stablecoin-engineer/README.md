# Stablecoin Example Prompts

Use `stablecoin-engineer` for prompts such as:

```text
Write a design review for an overcollateralized stablecoin with multiple collateral types, debt ceilings, a redemption facility, liquidations, reserve accounting, and emergency shutdown.
```

Expected behavior: classify the stability model, separate onchain liabilities from offchain assumptions, and avoid guaranteeing peg or redemption.
