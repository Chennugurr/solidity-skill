# RWA Token Example Prompts

Use `rwa-token-engineer` for prompts such as:

```text
Design technical controls for a tokenized asset with expiring eligibility attestations, restricted transfers, issuer mint/burn, freeze authority, redemption records, and complete privileged-event auditability.
```

Expected behavior: translate only approved requirements into code, disclose administrator and custody powers, minimize onchain personal data, and require qualified legal review.
