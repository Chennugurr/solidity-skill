# Cross-Chain L2 Example Prompts

Use `cross-chain-l2-engineer` for prompts such as:

```text
Design an L1-to-L2 configuration message flow for an OP Stack chain and Arbitrum. Authenticate the remote sender, prevent replay, define retries and cancellation, and document finality and address-aliasing differences.
```

Expected behavior: bind the full message domain, separate chain-family behavior, define failure recovery, and verify canonical addresses from current official sources.
