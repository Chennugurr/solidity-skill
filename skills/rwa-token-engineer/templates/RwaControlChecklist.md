# RWA Control Checklist

- [ ] Asset claim, issuer, custodian, and redemption path documented
- [ ] Eligibility evidence, scope, expiry, revocation, and privacy reviewed
- [ ] Transfer, mint, burn, freeze, seizure, and policy powers separated
- [ ] Every privileged action observable and independently reviewable
- [ ] Supply reconciles with the authoritative offchain registry
- [ ] Failed custody, settlement, and migration behavior defined
- [ ] Qualified legal review completed for every target jurisdiction
