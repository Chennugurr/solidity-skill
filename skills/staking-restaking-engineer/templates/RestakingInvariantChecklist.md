# Restaking Invariant Checklist

- [ ] Active and queued shares reconcile to stake and declared losses
- [ ] Rewards, fees, and slashes update before share changes
- [ ] Queued withdrawals remain slashable for the declared window
- [ ] Requests cannot be skipped, duplicated, or claimed twice
- [ ] Operator registration, removal, and key rotation are authorized
- [ ] Validator exits and external service failures have defined outcomes
