# Slashing And Withdrawals

- Define the slashable window and which queued withdrawals remain slashable.
- Allocate slash and reward changes consistently across active and queued shares.
- Prevent double claims, queue skipping, timestamp manipulation, and stale exchange rates.
- Define partial liquidity, delayed finality, failed validator exits, and emergency claims.
- Test slashing before request, after request, before finalization, and after claim.
- Reconcile active stake, queued claims, claimed assets, fees, rewards, and losses.
