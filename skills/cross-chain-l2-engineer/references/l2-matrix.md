# L2 Application Matrix

| Family | Application checks |
| --- | --- |
| OP Stack / Base | L1/L2 messenger pair, reported sender, address aliasing, output/fault-proof finality, withdrawal delay |
| Arbitrum | inbox/outbox authentication, retryable lifecycle, aliasing, delayed inbox, challenge and confirmation behavior |
| ZKsync / Scroll | system contracts, deployment bytecode rules, proof finality, fee token and verification differences |
| Polygon PoS / CDK | checkpoint or validator trust, proof mode, data availability, bridge mapping, exit/finality behavior |

For every target, verify current official addresses and chain behavior instead of copying values from another network.
