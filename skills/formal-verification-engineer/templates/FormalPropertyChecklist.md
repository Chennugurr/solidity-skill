# Formal Property Checklist

- [ ] Natural-language requirement reviewed
- [ ] Assets, actors, units, and environmental assumptions explicit
- [ ] Positive example demonstrates reachability
- [ ] Intentionally failing control demonstrates sensitivity
- [ ] Unsupported opcodes, calls, and cheatcodes recorded
- [ ] Loop, array, time, and numeric bounds recorded
- [ ] Vacuity and over-constraint checked
- [ ] Counterexamples reproduced as concrete regression tests
- [ ] Unverified behavior listed in the result
