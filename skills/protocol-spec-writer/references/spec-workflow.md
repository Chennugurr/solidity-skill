# Spec Workflow

## 1. Goal

State the protocol goal in one or two paragraphs. Include what the system must not do.

## 2. Actors

List all actors:

- Users.
- Admins.
- Operators.
- Keepers.
- Treasury.
- Token issuers.
- Governance.
- External protocols.
- Attackers.

## 3. Assets

List:

- ERC20 tokens.
- Native ETH.
- NFTs or positions.
- Shares.
- Rewards.
- External claims.

Define custody for each asset.

## 4. Contracts

List contracts and responsibilities. Keep contracts minimal and cohesive.

## 5. Flows

Describe user and admin flows step by step:

- Inputs.
- State changes.
- External calls.
- Events.
- Reverts.

## 6. Trust Assumptions

Document:

- Admin powers.
- Oracle trust.
- Upgrade authority.
- External protocol assumptions.
- Keeper assumptions.
- Emergency controls.
