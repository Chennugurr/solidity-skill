# Solver Security

- Define open, allowlisted, auction-selected, or exclusive solver participation.
- State who receives price improvement and how fees are disclosed.
- Prevent solver-selected callbacks from escalating token approvals or reentering settlement state.
- Bound gas sponsorship and griefing.
- Model censorship, failed auctions, stale quotes, unavailable liquidity, and private-order leakage.
- Test front-running cancellation, duplicated fills, fill ordering, malicious tokens, callback reentrancy, and recipient substitution.
