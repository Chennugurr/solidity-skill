# Token Launch Checklist

## Token Mechanics

- [ ] Name and symbol confirmed.
- [ ] Supply fixed or mint authority disclosed.
- [ ] Decimals confirmed.
- [ ] Burn behavior documented.
- [ ] Pause behavior documented or absent.
- [ ] Taxes documented or absent.
- [ ] Blacklist/allowlist documented or absent.
- [ ] Transfer limits documented or absent.
- [ ] Upgradeability documented or absent.

## Supply And Allocations

- [ ] Total supply allocated.
- [ ] Team allocation documented.
- [ ] Investor allocation documented.
- [ ] Treasury allocation documented.
- [ ] Liquidity allocation documented.
- [ ] Vesting or lock terms documented.

## Liquidity

- [ ] Pool/router chosen.
- [ ] Initial liquidity amount confirmed.
- [ ] LP recipient confirmed.
- [ ] LP lock/burn/treasury plan documented.
- [ ] Claims about locked liquidity are verifiable.

## Admin And Disclosure

- [ ] Owner/admin powers listed.
- [ ] Multisig plan documented.
- [ ] Tests cover privileged functions.
- [ ] Mainnet risk disclosure included.
