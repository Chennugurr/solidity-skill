# Solidity Agent Skills Suite v2.0.0

This release expands the suite from nine to twenty independently loadable,
vendor-neutral Solidity skills while preserving every existing skill name.
These notes are documentation only; operational examples start with dry-run
validation and do not execute live transactions.

## Highlights

- Adds account abstraction, oracle integration, protocol operations, formal
  verification, and cross-chain/L2 engineering roles.
- Adds lending/liquidation, stablecoin, perpetuals/funding, intent/solver,
  staking/restaking, and RWA technical-control specialists.
- Splits broad protocol guidance into focused signature, oracle, L2,
  reproducible-build, operations, modern EVM, and MEV references.
- Adds five pinned standalone Foundry projects with unit, fuzz, invariant,
  script, README, and audit-note coverage.
- Adds deterministic prompt evaluations for all twenty skills.
- Adds blocking SMTChecker, Halmos `0.3.3`, and OpenZeppelin upgrades-core
  `1.46.0` validation. Slither remains non-blocking and intended for triage.
- Pins v2 examples to Solidity `0.8.36`, OpenZeppelin `5.6.1`, and forge-std
  `1.16.2`; provider dependencies are locked where used.

## Distribution

Release assets include twenty single-skill upload archives, a source archive,
and `SHA256SUMS`. Codex and Claude Code plugin manifests now report `2.0.0` and
continue to load the vendor-neutral root `skills/` payload.

No CLI, MCP server, app, hooks, marketplace entry, or installer is included.

## Safety

All templates and example projects are educational drafts. Rehearse privileged
actions in isolated environments, verify assumptions, run appropriate tests,
obtain independent security review, and commission audits before mainnet use.
RWA workflows require qualified legal review. Formal results apply only to the
properties, assumptions, and bounds that were checked.
