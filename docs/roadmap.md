## Near Term

- Add more compile-checked Solidity templates.
- Add Hardhat notes without making Hardhat the default.
- Add ERC721, ERC1155, ERC4626, Merkle claim, and vesting templates.
- Add example full project outputs.
- Add optional install helpers after the Markdown V1 suite stabilizes.

## Quality Goals

- Keep core skills vendor-neutral.
- Keep templates minimal, transparent, and auditable.
- Add tests or compile checks for templates where practical.
- Document security assumptions without implying generated code is automatically safe.
- Keep shared references small, reusable, and directly linked from each skill.
